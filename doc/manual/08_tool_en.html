Chapter 8: Tools

TableEngine includes built-in viewers for inspecting file contents. These are accessible from the Tools menu.

Text Viewer

Tools › View File   V
Opens the selected file in the built-in text viewer. Supports text files, HTML, Markdown, and other markup formats.

  • Syntax highlighting for source code files
  • Automatic character encoding detection
  • Toggle word wrap
  • Rendered display for Markdown and other markup formats
Select a file in the list and press V (or use Tools › View File) to open it quickly.

Binary Viewer

Tools › View Binary   B
Opens the selected file in a hex dump viewer. Use this for binary files or files that cannot be displayed correctly in the text viewer.

  • Side-by-side hexadecimal and ASCII display
  • Offset (address) column
  • Search (text / binary / number)
  • Numeric decode pane (Int8–Int64 / endian switch)
  • Jump to a specified offset
Both viewers are read-only. File contents cannot be modified.

Editing with External Editors

In addition to the built-in viewers, you can open and edit files with registered external editors. The editors to use are registered in advance via Tool Setting.

Edit File

Tools › Edit File
Opens the selected file in the registered external text editor.

Edit Binary

Tools › Edit Binary
Opens the selected file in the registered external binary editor.

Tool Setting

Tools › Tool Setting
Registers the text / image / binary edit commands and the list of user-defined tools.

→ Dialog details: Tool Setting Dialog

User Commands

Register frequently used external commands as “user commands” and run them against the selected items in the file list. Up to 31 commands can be registered.

Register User Commands

User › Register User Commands
Registers and edits commands. Command strings can use placeholders that represent the selected file paths (%F / %f / %M / %m / %P).

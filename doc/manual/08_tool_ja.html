第8章 ツール

TableEngine にはファイルの内容を確認するためのビューアが内蔵されています。 これらは ツール メニューからアクセスできます。

テキストビューア

ツール › ファイルを表示
選択中のファイルを内蔵のテキストビューアで表示します。 テキストファイル・HTML・Markdown などのマークアップファイルに対応しています。

  • シンタックスハイライト対応（コードファイル）
  • 文字コードの自動判別
  • 折り返し表示の切り替え
  • Markdown などのマークアップはレンダリング表示
ファイルリストでファイルを選択し、ツール › ファイルを表示 を実行するか、 割り当てたショートカットキーで素早く開けます。

バイナリビューア

ツール › バイナリを表示
選択中のファイルを 16進数ダンプ形式で表示します。 バイナリファイルや、テキストビューアでは正しく表示できないファイルの内容確認に使用します。

  • 16進数表示 + ASCII 表示の並列表示
  • オフセット（アドレス）表示
  • 検索（テキスト / バイナリ / 数値）
  • 数値デコード表示（Int8〜Int64 / エンディアン切替）
  • オフセット指定でのジャンプ
ビューアは読み取り専用です。ファイルの内容を変更することはできません。

外部エディタで編集

内蔵ビューアとは別に、登録した外部エディタでファイルを開いて編集できます。 使用するエディタは「ツール設定」であらかじめ登録します。

ファイルを編集

ツール › ファイルを編集
登録した外部テキストエディタで、選択中のファイルを開きます。

バイナリを編集

ツール › バイナリを編集
登録した外部バイナリエディタで、選択中のファイルを開きます。

ツール設定

ツール › ツール設定
テキスト・画像・バイナリの各編集コマンドと、ユーザー定義ツールの一覧を登録します。

→ ダイアログの詳細: ツール設定ダイアログ

ユーザーコマンド

よく使う外部コマンドを「ユーザーコマンド」として登録し、ファイルリストの選択項目に対して実行できます。 最大 31 個まで登録できます。

ユーザーコマンドの登録

ユーザー › ユーザーコマンドの登録
コマンドの登録・編集を行います。コマンド文字列では、選択中のファイルパスなどを表すプレースホルダ （%F / %f / %M / %m / %P）が利用できます。

→ ダイアログの詳細: ユーザーコマンド登録ダイアログ
